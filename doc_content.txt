makePayment(user, merchant_id, amount)
Inputs: authenticated user, merchant_id, amount. Preconditions: user is logged in; wallet belongs to that user's student. Validate amount > 0; wallet exists; merchant exists. Artifact: Language-independent pseudocode for the selected algorithm, including approved rules and important edge cases.
Approved language-independent pseudocode – makePayment
FUNCTION makePayment(user, merchant_id, amount)
    BEGIN TRANSACTION
    IF amount <= 0 THEN ROLLBACK; RETURN error
    wallet ← wallet belonging to the logged-in user's student
    IF wallet NOT FOUND THEN ROLLBACK; RETURN 'Wallet not found'
    merchant ← merchant identified by merchant_id
    IF merchant NOT FOUND THEN ROLLBACK; RETURN 'Merchant not found'
    IF approved policy requires non-negative balance AND wallet.balance < amount
        THEN ROLLBACK; RETURN 'Not enough balance'
    wallet.balance ← wallet.balance - amount
    payment ← INSERT payment(wallet, merchant, amount, current_time)
    IF payment satisfies the approved cashback rule THEN
        INSERT cashback(payment, approved_cashback_amount, current_time)
    COMMIT
    RETURN payment
ON ANY ERROR: ROLLBACK all changes and return failure
END FUNCTION
Important unresolved rules: confirm whether balance may go below zero and define cashback eligibility/amount before activating those checks.
